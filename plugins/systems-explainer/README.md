# systems-explainer (plugin)

Turns any topic or source document into single-page web apps: an **educational blueprint explainer**, a **detailed reference guide**, or **both**, cross-linked and sharing one palette.

Skills:
- `blueprint-explainer`: the educational version
- `reference-guide`: the detailed version
- `update-playbook`: folds new patterns and corrections into the playbooks

Install, usage and development notes are in the repository README: https://github.com/elmiller9/systems-explainer
